# EcoDescarte 🌱

Projeto extensionista de TI Verde para gestão de coleta de lixo eletrônico em uma escola de educação infantil.

## Tecnologias Utilizadas
- HTML5, CSS3 e JavaScript
- Supabase (Banco de dados PostgreSQL na nuvem)
- Netlify (Hospedagem)

## Funcionalidades
- Cadastro de Turmas
- Cadastro de Alunos
- Registro de Coletas de Lixo Eletrônico (CRUD completo)
- Ranking automático das turmas
